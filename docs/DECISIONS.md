| D-084 | 2026-11-27 | Background jobs run in-process with APScheduler, started from the FastAPI lifespan only when `JOBS_ENABLED=true` (default false; true in `.env.prod.example`). | D-086 | 2026-11-27 | Jobs lock recovery: every worker with `JOBS_ENABLED` runs a supervisor. Postgres grants the session lock to one session only, so there are never two holders (a dead holder's lock is freed when its session ends) | Jobs must survive a lost connection or a dead worker without running twice | Replace with a dedicated worker or a queue (D-084) |
